set_first_password(user, password=None, set_current=False)[source]

Call POST /v1/users/{user}/set-first-password.

If password is None, linuxmuster-api resets the user’s current password back to their existing first password instead of setting a new one (set_current is then meaningless and ignored on that path).

set_current_password(user, password, set_first=False)[source]

Call POST /v1/users/{user}/set-current-password.

set_random_first_password(user)[source]

Call POST /v1/users/{user}/set-random-first-password: linuxmuster-api generates a password satisfying the current password policy and sets it as the user’s first and current password.

Returns:

the generated password

check_first_password(user)[source]

Call GET /v1/users/{user}?check_first_pw=true.

Returns:

True if the user’s current password still matches their stored first password, False otherwise.

get_first_password(user)[source]

get_user_quotas(user)[source]

Call GET /v1/users/{user}/quotas.

Unlike sophomorix-query, this resolves quotas hosted on a separate fileserver (MSDFS) instead of always querying the local domain controller.

Returns:

{<share>: {‘used’, ‘soft_limit’, ‘hard_limit’} or {‘ERROR’: …}, …, ‘cloud’: …, ‘mail’: …}

add_management_group_members(group, users, school)[source]

Call POST /v1/managementgroups/{group}/members to add users (wifi, internet, intranet, webfilter, printing) to a management group.

school is required: linuxmuster-api has no notion of the webui’s current school context, and a global-administrator’s own JWT carries no single school at all.

remove_management_group_members(group, users, school)[source]

Call DELETE /v1/managementgroups/{group}/members to remove users from a management group. See add_management_group_members for school.

add_parent(student, parent)[source]

Call POST /v1/users/{student}/parents to assign an existing parent to an existing student.

remove_parent(student, parent)[source]

Call DELETE /v1/users/{student}/parents to unassign a parent from a student.

patch_printer_members(printer, changes)[source]

Call PATCH /v1/printers/{printer} to add or remove members and member groups in a single LDAP modify, instead of one sophomorix-group call per entity.

changes maps the API’s list fields (addmembers, removemembers, addmembergroups, removemembergroups) to lists of cn. Attributes that are not sent are left untouched.

Reserved to administrators by the API (RoleChecker “GS”). Unlike the management group routes, this one takes no school: it reads it from the caller’s JWT, and printer names already carry their school prefix in a multischool setup.

join_printer(printer)[source]

Call POST /v1/printers/{printer}/join to add the caller themselves to a joinable printer. This is the route a teacher may use: the API checks sophomorixJoinable and ignores any member name sent to it.

quit_printer(printer)[source]

Call POST /v1/printers/{printer}/quit to remove the caller themselves from a printer. See join_printer.
